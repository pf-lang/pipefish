Pipefish is meant to be a simple language. But you can do some advanced things in it as needed.

* [Interface types, part 2](https://github.com/tim-hardcastle/Pipefish/wiki/Interface-types,-part-2) : we look at how interface types allow modules to share functions.
* [Reference parameters](https://github.com/tim-hardcastle/Pipefish/wiki/Reference-parameters) : in Imperative Pipefish, you can't return a value, but you can pass a variable to be operated on.
* [SQL interop](https://github.com/tim-hardcastle/Pipefish/wiki/SQL-interop) : built-in interop with everyone's favorite relational database.
* [Microservices](https://github.com/tim-hardcastle/Pipefish/wiki/Microservices) : learn how your services can interact with one another.
* [Golang interop](https://github.com/tim-hardcastle/Pipefish/wiki/Golang-interop) : built-in Golang interop.
* [Wrapper types](https://github.com/tim-hardcastle/Pipefish/wiki/Wrapper-types) : wrap any Go type in a Pipefish type.
* [Roll your own IO](https://github.com/tim-hardcastle/Pipefish/wiki/Roll-your-own-IO) : a combination of the preceding features helps you to write your own IO commands to interact with whatever database/webservice/etc you like.
* [Snippets](https://github.com/tim-hardcastle/Pipefish/wiki/Snippets) : embed the language of your choice.
* [Embedding Pipefish in Go](https://github.com/tim-hardcastle/Pipefish/wiki/Embedding-Pipefish-in-Go) : how to do that.
