Welcome to Pipefish Author. You can use this website to create, edit, and publish Pipefish books.

We assume that you have already seen one or two Pipefish books. If so, you will realize that you're reading another one, but that it has a couple of extra dropdown menus and one more button. These allow you to edit books, including this book you're reading, which is supplied as a tutorial and playground. If you regret your edits nd want to know what the book originally said, there is an option "Revert sample book" in the dropdown "Books" menu.

This is a static website: your work is stored locally in your browser, which is why you haven't been asked to register for anything. For more permanent storage, you can use the "Books" menu either to download your work, or to publish it to GitHub Pages, which is after all what Pipefish Author exists for.

In the next section of the book we will explain how to use the extra controls to edit and publish books, and in the final section we will look at how to make Pipefish code run in a book and interact with the various widgets you can put in your pages.
